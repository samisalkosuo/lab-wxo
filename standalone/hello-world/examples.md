# hello_world — Examples

Example prompts for the `hello_world` agent, with the expected behaviour.

1. *"Hello"* — agent calls the `greeting` tool and replies `Hello World!`.
2. *"Greeting"* — agent calls the `greeting` tool and replies `Hello World!`.
3. *"What's the weather today?"* — agent does not call the tool; it replies helpfully and says it can greet the user.
